# 🚨 SafeWay — Plataforma de Alertas Comunitários

## 📌 Sobre o projeto

O **SafeWay** é uma plataforma voltada à segurança comunitária, desenvolvida com o objetivo de facilitar o compartilhamento de informações sobre riscos e ocorrências em diferentes regiões.

Inspirado em ferramentas de navegação colaborativa, como o Waze, o projeto busca conectar pessoas por meio de alertas geolocalizados, permitindo que os usuários consultem situações que possam comprometer sua segurança ou mobilidade.

A proposta é incentivar a colaboração entre cidadãos, promovendo o acesso a informações relevantes e contribuindo para a prevenção de situações de risco.

## 🎯 Objetivos

- Facilitar a identificação de riscos e ocorrências nas proximidades.
- Permitir o registro e compartilhamento de alertas comunitários.
- Disponibilizar informações organizadas por localização e categoria.
- Incentivar a colaboração e a conscientização da comunidade.
- Melhorar o acesso a informações sobre segurança e infraestrutura urbana.

## 🛠️ Funcionalidades

O projeto contempla as seguintes funcionalidades:

- **Mapa de riscos:** visualização de ocorrências geolocalizadas.
- **Registro de ocorrências:** formulário para envio de novos alertas.
- **Filtros:** organização das ocorrências por categoria e localização.
- **Mural comunitário:** espaço para consulta e compartilhamento de informações.
- **Notificações:** possibilidade de receber alertas sobre situações próximas.
- **Autenticação e perfil:** gerenciamento de acesso e informações dos usuários.
- **Confiabilidade das informações:** identificação da origem e do nível de verificação das ocorrências.

*Observação: as funcionalidades estão em desenvolvimento e serão disponibilizadas progressivamente.*

## ⚙️ Como executar o projeto

### 1. Pré-requisitos

Antes de iniciar, é necessário possuir:

- Node.js instalado.
- npm (gerenciador de pacotes do Node.js).
- Git.
- Visual Studio Code ou outro editor de código.

### 2. Clonar o repositório

```bash
git clone https://github.com/MariPaiva490/Landing-Page-Alertas.git
```

### 3. Acessar a pasta do projeto

```bash
cd Landing-Page-Alertas
```

### 4. Instalar as dependências

```bash
npm install
```

### 5. Executar o projeto

```bash
npm run dev
```

Após a inicialização, o Vite disponibilizará um endereço local no terminal, geralmente:

```text
http://localhost:5173/
```

Acesse esse endereço pelo navegador para visualizar a aplicação.
